# Resources

A short list of things outside this site that you might want to bookmark.

## Run it without installing

- [StackBlitz live editor](https://stackblitz.com/edit/namefully) — fork it, edit it, see the console.

## Where to ask questions

- [GitHub Issues](https://github.com/ralflorent/namefully/issues) — for bug reports and feature requests.
- [Stack Overflow](https://stackoverflow.com/questions/tagged/namefully) — for usage questions. Use the `namefully` tag so the maintainer sees it.

## Packages

- [npm: namefully](https://www.npmjs.com/package/namefully) — the canonical TypeScript/JavaScript package.
- [JSR: @ralflorent/namefully](https://jsr.io/@ralflorent/namefully) — for Deno and Bun users who prefer JSR.

## Source and history

- [GitHub: ralflorent/namefully](https://github.com/ralflorent/namefully) — the library itself.
- [Changelog](https://github.com/ralflorent/namefully/blob/main/changelog.md) — version history with release notes.
- [DeepWiki](https://deepwiki.com/ralflorent/namefully) — an alternative, auto-generated view of the repository.

## Reading

- [UK naming-practice guide (PDF)](https://www.fbiic.gov/public/2008/nov/Naming_practice_guide_UK_2006.pdf) — the standard the library's slot model is based on.

## Contributing

If you'd like to contribute code or docs, the [Contributing](../contributing) page walks through the dev loop. The library's [`CONTRIBUTING.md`](https://github.com/ralflorent/namefully/blob/main/CONTRIBUTING.md) and [`CODE_OF_CONDUCT.md`](https://github.com/ralflorent/namefully/blob/main/CODE_OF_CONDUCT.md) cover the broader contribution norms.
